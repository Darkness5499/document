# 1. Kết nối Spring Boot Application với Redis và thao tác cơ bản

## 1.1. Add Redis Dependency

Spring Boot sử dụng **Spring Data Redis** để giao tiếp với Redis.

`pom.xml`

```
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-redis</artifactId>
</dependency>
```

Spring Boot mặc định sử dụng:

```
Spring Data Redis
        |
        |
     Lettuce Client
        |
        |
    TCP Socket
        |
        |
     Redis Server
```

----------

## 1.2. Cấu hình Redis Connection

`application.yml`

```
spring:
  data:
    redis:
      host: localhost
      port: 6379
      password: your_password
```

Mặc định:

```
Host: localhost
Port: 6379
Protocol: TCP
```

----------

## 1.3. Tạo RedisTemplate Configuration

Spring Boot đã tự tạo `RedisTemplate`, nhưng trong thực tế thường custom serializer.

Ví dụ dùng JSON serializer:

```
@Configuration
public class RedisConfig {

    @Bean
    public RedisTemplate<String, Object> redisTemplate(
            RedisConnectionFactory connectionFactory) {

        RedisTemplate<String, Object> template =
                new RedisTemplate<>();

        template.setConnectionFactory(connectionFactory);

        return template;
    }
}
```

# 2. RedisTemplate là gì?

`RedisTemplate` là abstraction giúp Java thao tác Redis mà không cần viết trực tiếp Redis command.

Mapping:

```
RedisTemplate
      |
      |
  opsForXXX()
      |
      |
Redis Data Type
```

Ví dụ:

Java API

Redis Type

`opsForValue()`

String

`opsForHash()`

Hash

`opsForList()`

List

`opsForSet()`

Set

`opsForZSet()`

Sorted Set

----------

# 3. Thao tác Redis cơ bản trong Spring

## 3.1. String (Key-Value)

Redis:

```
SET username Alex

GET username
```

Java:

```
@Service
public class RedisService {

    @Autowired
    private RedisTemplate<String, Object> redisTemplate;


    public void save() {

        redisTemplate.opsForValue()
                .set(
                    "username",
                    "Alex"
                );
    }


    public Object get() {

        return redisTemplate.opsForValue()
                .get("username");
    }
}
```

----------

## 3.2. Set Expiration (TTL)

Redis:

```
SET token abc123

EXPIRE token 3600
```

Java:

```
redisTemplate.opsForValue()
        .set(
            "token",
            "abc123",
            Duration.ofHours(1)
        );
```

Use case:

-   JWT Token
-   Session
-   Cache

----------

## 3.3. Kiểm tra key tồn tại

Redis:

```
EXISTS username
```

Java:

```
Boolean exists =
        redisTemplate.hasKey("username");
```

----------

## 3.4. Delete Key

Redis:

```
DEL username
```

Java:

```
redisTemplate.delete("username");
```

# 4. Hash thao tác Object

Redis Hash phù hợp lưu object dạng field-value.

Redis:

```
HSET user:1001 name Alex age 26
```

Java:

```
redisTemplate.opsForHash()
        .put(
            "user:1001",
            "name",
            "Alex"
        );
```

Lấy:

```
Object name =
    redisTemplate.opsForHash()
        .get(
            "user:1001",
            "name"
        );
```

Use case:

-   User Profile
-   Product Information
-   Configuration

----------

# 5. StringRedisTemplate

Nếu chỉ thao tác String:

```
@Autowired
private StringRedisTemplate redisTemplate;
```

Ví dụ:

```
redisTemplate.opsForValue()
        .set(
            "access_token",
            "abc123"
        );
```

Phù hợp:

-   JWT blacklist
-   Distributed lock
-   Counter
-   Simple cache

# Why is Redis Fast?

Redis is fast because:

- **In-memory storage:** Data is stored primarily in RAM, avoiding slow disk I/O.
- **Simple data structures:** Redis uses optimized data structures (String, Hash, List, Set, Sorted Set) with efficient operations.
- **Single-threaded command execution:** Avoids thread context switching and locking overhead for most operations.
- **Efficient protocol:** Uses a lightweight binary-safe protocol (RESP) instead of HTTP overhead.
- **Event-driven architecture:** Uses non-blocking I/O to handle many connections efficiently.

In short:

> Redis is fast because it keeps data in memory, uses optimized data structures, minimizes overhead, and provides low-latency access.
